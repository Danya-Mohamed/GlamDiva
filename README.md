# GlamDiva 

GlamDiva is a fashion e-commerce website project that allows users to browse products, register, login, and simulate shopping.

---

## ✨ Features
- User registration and login
- Product browsing (dresses, accessories, etc.)
- Shopping cart simulation
- Profile page
- Payment UI design
- light/dark mode implmentation

---

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- Java
